Design notes — read before reviewing fields
What changed vs. the old flat 13-sub-tab Key Inference
  • Restructured into a 6-step numbered flow (step 2 has two sub-steps). Each step pairs one hand-rolled SVG chart with one primary table — no charting library, same rule the chart diagrams already follow (design-language.md).
  • Step 3 (Strength) bends the one-table rule on purpose: Planet Strength and House Strength are two short, related tables under one chart, not one merged table with mismatched columns.
  • Step 4 (Planet-Chart) bends it the most: Vargottama, Ṣoḍaśavarga, Vaiśeṣikāṁśa and Varga Dignity are four angles on the same 16-varga dataset, so they share one chart (Vaiśeṣikāṁśa stacked bars) and one primary table (the Ṣoḍaśavarga grid); Vargottama and Varga-Dignity surface as inline tags/chips rather than two more tables.
New fields — sourcing status
  • Exaltation point + closeness (step 2.2): exaltation degrees are the classical Uchcha Bindu (Sun 10° Ari · Moon 3° Tau · Mars 28° Cap · Mercury 15° Vir · Jupiter 5° Can · Venus 27° Pis · Saturn 20° Lib — Rahu/Ketu excluded, no classical exaltation point). Closeness % = (1 − Δ° / 180) × 100 where Δ is the angular distance from the planet's own exaltation point. Not yet a DB column — computed here from tbl_Chart_KeyDetails.NirayanaLongitudeDegrees; a real build adds the 7 exaltation constants as a small rule table (tbl_Rule_Exaltation) rather than hard-coding them in the view.
  • Yoga Type (Sun / Moon / Lagna / combination) and short Rule (step 6): not in the DB today. tbl_Rule_Yoga has FormationFamilyCode and RequirementJson but neither is a clean "reference point" or "one-line rule" field. The values shown are hand-derived from the classical definitions for illustration — a real build needs either a parser over RequirementJson or two new columns on tbl_Rule_Yoga.
  • "Own/Exalt in" varga list (step 4): real, from tbl_Chart_KeyDetails.DignityStatus grouped by ChartType across the 16 vargas — answers "where is this strength coming from".

  • Special Lagnas (Hora Lagna, …) — step 2.1 card. tbl_Chart_KeyDetails · PointKind='SpecialLagna'.
  • Per-planet nakṣatra + pāda — moved into the step-1 D1 table (was buried in Planet Dignity only).

  • Conjunction groups — step 2.1, listed per house. tbl_Chart_MultiGrahaConjunction(+Member).
  • Planetary avasthās (Bālādi / Jāgradādi) — still pending a table home; not added this round.
